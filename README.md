# Вертушка

Музыкальный плеер с визуализациями в одном HTML-файле. Играет файлы с компьютера, ничего никуда не загружает.

Открыть: https://egm-demo.github.io/vertushka/

Или скачать `Vertushka.html` и открыть двойным кликом в Chrome.

## Что внутри

- 31 визуализация: классика, сцены, шейдеры на WebGL, «Рандом» и две игры (шоссе в Нью-Йорке и трасса через поле в России).
- 20 тем оформления.
- Звук из VK Музыки, Яндекс Музыки и Spotify: музыка играет в сервисе, Вертушка слушает звук вкладки и рисует под него.

Сборка: `python src/build.py` собирает `Vertushka.html` из `src/`.
