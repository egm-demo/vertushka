# Вертушка

Музыкальный плеер с визуализациями в одном HTML-файле. Играет файлы с компьютера, ничего никуда не загружает.

Открыть: https://egm-demo.github.io/vertushka/

Или скачать `Vertushka.html` и открыть двойным кликом в Chrome.

## Что внутри

- 31 визуализация: классика, сцены, шейдеры на WebGL, «Рандом», «Анализатор» (спектр в дБ, полосы, датчики бочки, малого, тарелок и синта) и игра «Шоссе: Нью-Йорк» с дрифтом и видом от руля. Стрелки ← → листают визуализации.
- Режим «Клип» (клавиша A): Вертушка сама подбирает визуализации под энергию трека и меняет их по тактам, на дропах и в затишьях.
- 22 темы оформления, по умолчанию светлая бело-серая.
- Звук из VK Музыки, Яндекс Музыки и Spotify: музыка играет в сервисе, Вертушка слушает звук вкладки и рисует под него.

- Игры в 3D: машиной рулишь сам (стрелки или WASD, пробел ручник, Shift нитро, C вид).
- Окно «Закинь сюда музыку» открывается кнопкой с папкой вверху справа (или клавишей O).

Сборка: `python src/build.py` собирает `Vertushka.html` из `src/`. Внутрь вшит three.js r149 (MIT, `vendor/three.LICENSE`).
